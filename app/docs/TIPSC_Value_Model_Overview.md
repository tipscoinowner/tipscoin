# TIPSC Value Model Overview

TIPSC, bu chain’in native varlığıdır ve governance tarafından tanımlanan bir hedef değere sahiptir:

- **Model:** Soft-pegged, reserve-backed, governance-controlled
- **Target Value:** 1 TIPSC = 1.00 reference units (başlangıç)
- **Reserves:** On-chain ReserveManager sözleşmesi ile izlenir
- **Health:** Reserve ratio, minReserveRatio eşiğine göre değerlendirilir
