# TIPSC Chain

TIPSC, bu chain’in native varlığıdır.  
Değeri governance tarafından tanımlanır ve ReserveManager tarafından izlenen on-chain rezervlerle desteklenir.

## Quick Start

git clone  
npm install  
npx hardhat node  
npx hardhat run scripts/deploy.ts --network local  
cd app && npm install && npm run dev
